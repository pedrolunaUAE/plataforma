Servidor compartido

El proxy es la unica entrada web. Cada proyecto sigue en su contenedor y en su carpeta.

  • OVIE http://localhost/ovie/
  • Cuadernillos IPLANAY http://localhost/iplanay/
  • MxSIG Compostela http://localhost/geovisor/
  • MxSIG cliente base http://localhost/mdm-client/
  • pgAdmin http://localhost/pgadmin/

La base de todos los proyectos es el Postgres de este mismo compose. OVIE usa la base ovie. MxSIG usa la base compostela. Los cuadernillos usan la base iplanay.
